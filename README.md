# UNDERGROUND HONEY — 프로그램 소개 사이트

로컬에서 `index.html`을 브라우저로 열면 됩니다. (BGM 자동재생 정책 때문에 반드시 스플래시 로고를 **터치/클릭**해야 입장·음악이 시작됩니다.)

## 플로우
1. `logo_compl.png` 스플래시 → 터치 시 BGM(`uhbgm.mp3`) + 글래스 샤터/글리치 트레일러
2. 프로그램 브리핑 (블랙 코미디 톤)
3. 출연자 도감 (3:4 포스터) → 메기 2명 비밀번호 락
4. **블랙 하이브 순찰** SVG 미니게임 (바/풀/가든/흡연실 단서 수집)

## 추가가 필요한 에셋 (플레이스홀더)
HTML/`index.html` 상단 주석과 동일합니다.

| 파일 | 용도 |
|------|------|
| `assets/hive_exterior.jpg` | 히어로 풀블리드 배경 (아와지섬 블랙 하이브 야경) |
| `assets/hive_bar.jpg` | 바 인테리어 (선택) |
| `assets/hive_pool.jpg` | 수영장 야경 (선택) |
| `assets/hive_garden.jpg` | 가든 (선택) |
| `assets/hive_smoke.jpg` | 흡연실 (선택) |
| `user_poster.png` | 12번째 출연자 `{user}` 3:4 포스터 |

현재 캐릭터 포스터는 `*_poster.png` 형식으로 레포에 포함되어 있습니다.
